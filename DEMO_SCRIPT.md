# Pathloom 3-Minute Demo Script

Public app: https://edu-path-hacathon-1.onrender.com

## 0:00-0:20 - Opening

Say:
"This is Pathloom, a personalized learning and skill-gap agent. Instead of giving everyone the same curriculum, it looks at what a learner already knows, identifies the gaps for a target role, and creates an adaptive path."

Show the Overview page and the cyberpunk dashboard styling.

## 0:20-0:45 - Example learner

Say:
"I will use a self-taught developer who knows HTML, CSS, basic JavaScript, and SQL, and wants to become a frontend developer."

Click **Load demo example**.

Point out:
- Frontend Developer target
- 4 identified gaps
- 4-week roadmap
- Live agent activity trail

## 0:45-1:20 - Agent result

Say:
"Pathloom separates existing skills from agent-identified gaps. The gaps include JavaScript and DOM interaction, React component thinking, portfolio polish, and interview storytelling."

Open **Skill Map**, then **Roadmap**.

Say:
"The roadmap turns those gaps into weekly objectives, resources, and a practical task. Week 1 builds responsive UI foundations, then the learner moves into JavaScript interaction, a portfolio sprint, and job-ready storytelling."

## 1:20-1:50 - Today workflow

Open **Today**.

Say:
"The learner does not have to manage the whole roadmap at once. Today shows the current week's objectives and one concrete practice task. Progress is saved as objectives are checked off."

Check one objective if useful.

## 1:50-2:35 - Ask AI

Open **Ask AI** and ask:

"What should I build in Week 3 to improve my frontend portfolio?"

Say:
"Ask AI answers using the learner's own plan. It recommends building a polished portfolio mini-project and explains how that connects to the week's objective."

If the AI service is slow, say:
"The app also has a local fallback, so the learner still gets a useful plan-grounded answer when an external model is unavailable."

## 2:35-3:00 - Close

Say:
"Pathloom makes learning adaptive at three levels: it starts from the learner's actual skills, changes the roadmap around progress, and answers questions in the context of that roadmap. The result is a practical path from current ability to a clear career goal."

Show the public URL:
https://edu-path-hacathon-1.onrender.com

## Demo checklist

- Open the public URL before recording.
- Click **Load demo example**.
- Show Skill Map.
- Show Roadmap.
- Show Today.
- Ask the Week 3 portfolio question.
- Keep the browser tab on the public URL.
- The free Render service may need a few seconds to wake up.
